# BabelBubble releases

This is the public release channel for **BabelBubble**, a one-tap screen
translator for Android. The source repository is private; only signed APKs,
checksums and release notes are published here.

## Install

1. Open the latest release and download the APK for your phone:
   - `arm64-v8a` for almost all phones from the last several years
   - `armeabi-v7a` for older 32-bit devices
2. Allow your browser or file manager to install unknown apps when Android asks.
3. Open the APK and confirm the install.

Once installed, BabelBubble checks this channel once a day and offers new
versions from **Settings → Updates**. Every download is verified against
BabelBubble's pinned release certificate before Android's installer is opened.

`SHA256SUMS.txt` lists the checksum of each release APK.
